# Overview

Creative North Star: The Living Catalog. Readora should feel like a curated archive where books are the heroes: physical, colorful, inspectable, and arranged with editorial confidence. The interface is quiet enough to work as a product, but distinctive enough to feel like a place.

The first viewport should show the actual library experience, not a marketing hero. Use spatial browsing through shelves, rails, featured objects, and reading progress. Motion should make books feel handled: selected, lifted, inspected, returned.

# Colors

Use a split palette rather than a beige or brown monoculture.

- Archive Black: `#0b0a09` for deep stage backgrounds.
- Warm Ink: `#1e1815` for main product surfaces.
- Bone Paper: `#f4efe4` for readable panels and text on dark.
- Soft Stone: `#d7d1c4` for secondary text.
- Brass: `#c78d3d` for focus, progress, and selected state.
- Library Green: `#2f5948` for grounded book objects.
- Oxblood: `#8e2f32` for editorial emphasis and book spines.
- Cobalt: `#1f5fbf` for rare electric contrast on book objects.
- Signal Red: `#e34234` for vivid book accents, not large UI surfaces.

# Typography

Use serif display type for editorial book titles and major moments. Use sans type for controls, metadata, filters, and dense product UI.

Display type should be large only where it creates hierarchy. Inside panels and controls, keep headings modest and readable. Letter spacing is 0 except small uppercase labels, where positive tracking is allowed.

# Elevation

Flat by default. Shadows should belong to physical books, shelf planes, modal overlays, and hover states. Use crisp object shadows rather than soft generic glows.

# Components

Navigation should feel like an archive console: compact controls, search, mode switch, and status without large chrome.

The immersive library uses a kinetic catalog wall:
- A central featured book or selected spine.
- Lateral spines and shelves for exploration.
- Filters as small archival labels.
- Progress as a physical mark on a spine or shelf.
- Inspection in a refined side panel.

Classic library remains a clean utility view with grid/list modes and no cinematic staging.

# Do's and Don'ts

Do make books colorful, specific, and textural.
Do use strong object hierarchy: selected book, neighboring spines, metadata, actions.
Do make motion reveal state and direction.
Do preserve fast search and reduced motion.

Don't make the app look like a room drawn with rectangles.
Don't rely on beige, tan, walnut, and brass alone.
Don't use generic cards for every section.
Don't add explanatory marketing copy inside the product surface.
