# Readora brand assets

The Readora mark combines an open book, a leaf-like flourish, and a quiet R monogram. It is intended to feel literary and warm rather than overtly technological.

- Primary mark: public/brand/readora-mark.svg
- Full lockup: public/brand/readora-wordmark.svg
- Core colors: walnut #3D2C20, leather #755038, brass #B98B46, parchment #F3EDE1, ink #241F1A

Use the mark on parchment, walnut, or quiet neutral surfaces. Preserve clear space equal to the mark's central spine. The React versions live in src/components/brand and should remain visually aligned with these exports.
